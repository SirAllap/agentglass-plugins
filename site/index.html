Listing is not auditing

A listed plugin has a public repository, a manifest the app accepts, a README and a licence, and it passed a scan for a short list of patterns. That is all a machine can check. It still runs as a process on your machine, and it still asks you to approve its scope. Read the code before you install anything, listed or not.

List yours

List your plugin at a commit anybody can read.

You do not need to be listed to be installed: anybody can install a plugin from its git URL today. The catalogue is for being found, and for being installed at a commit somebody could read.

Ship the repository.Public, with plugin.json at its root, a README that says what it does and what leaves the machine, and a LICENSE. A wide preview.png at the root becomes your card's picture.
Validate it.agentglass-plugin validate . applies the rules the app installs by.
Open the listing issue.A check clones the repository, validates it, scans the source and writes what it found on the issue.
A maintainer decides.On approval, a pull request adds your entry, pinned to the commit the check read.
Ready to be listed?A push after you are listed changes nothing for anybody who installs from here. A new version is a new submission.
